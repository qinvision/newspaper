# newspaper · 中国报纸名录

杜绝加密空间旗下子站：**https://newspaper.mydjjm.cn**

## 这是什么

按中国邮政**发报刊省局**分类整理的全国报纸名录，把邮局报刊发行目录里的 1,233 种报纸做成一张可搜索、可编辑的网页。

- **1,233 种**报纸，覆盖 **31 个**省级地区（北京市 … 新疆维吾尔自治区）
- 每条记录字段：
  `报刊名称 · 邮发代号 · 刊期 · 单价(元) · 年价(元) · 产品分类 · 官网链接 · 数字报链接`
- 后两列链接为可编辑字段，留空时按邮发代号从内置表自动匹配官方站点。

## 功能

- **顶部搜索框**：按报刊名称 / 邮发代号 / 产品分类模糊匹配
- **左侧地区导航**：点击地区名滚动到对应省份分组
- **卡片视图**：名称 + 邮发代号 + 刊期 + 单价 / 年价 + 分类标签
- **🔒 编辑模式**：
  - 点工具栏「🔒 进入编辑模式」→ 输入密码（见下）
  - 开启后点卡片可改条目、标题右上角可新增
  - 所有改动只存于本机浏览器 `localStorage`（key: `paper2026_exp_mw576rl6`），**不写回仓库**
- **导入 / 导出数据**：编辑模式下可导出 JSON 备份，或把备份导回另一台机器
- **导出 HTML**：把当前数据连同页面导出为单个 HTML 文件留存
- **回到顶部**浮钮

## 技术

- 纯静态单文件 `index.html`，无后端、无数据库、无外部依赖
- 数据块用 `/* ===DATA_START=== */` … `/* ===DATA_END=== */` 标记，夹在中间的 `const DATA = [...]` 是全部目录数据
- 样式：米黄纸张底（`#f5f3ee`）+ 深棕主色（`#a6321f`），宋体大标题，移动端自适应
- 编辑密码在源码里以 XOR 混淆存放（`_x` / `_y` 两个常量），不出现明文

## 部署

- HTTPS：Pages 设置里勾选 Enforce HTTPS

## 边界

- 本站是**目录索引**，不转载、不存储任何新闻正文
- 官网 / 数字报链接以邮发代号为键映射到官方站点；链接失效请在浏览器内「编辑模式」里改，改完「导出数据」备份
- 数据初始来源为公开邮局报刊发行目录整理，个别条目可能已停刊或改版，以实际订阅窗口为准
