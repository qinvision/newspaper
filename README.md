# newspaper · 全国报纸数字版导航

杜绝加密空间旗下子站：**https://newspaper.mydjjm.cn**

## 这是什么

把国内 **790 份**可在线阅读的报纸数字版入口整理成一张按地域分类的导航页，点卡片直接跳到对应报社官方数字报。

- **790 份**报纸，按中央级 + 七大地理区分类：
  - 中央级 · 全国性报纸（95）
  - 华北（101）：北京 42、天津 3、河北 28、山西 14、内蒙古 14
  - 东北（21）：辽宁 8、吉林 5、黑龙江 8
  - 华东（261）：上海 22、江苏 44、浙江 46、安徽 41、福建 25、江西 23、山东 60
  - 华中（92）：河南 42、湖北 23、湖南 27
  - 华南（59）：广东 33、广西 19、海南 7
  - 西南（86）：重庆 9、四川 43、贵州 11、云南 18、西藏 5
  - 西北（75）：陕西 27、甘肃 19、青海 7、宁夏 9、新疆 13
- 链接全部指向报社官方数字报/官网，不转载、不缓存正文

## 功能

- **粘性顶部导航**：中央级 / 华北 / 东北 / 华东 / 华中 / 华南 / 西南 / 西北 快速锚点
- **卡片式网格**：按省份分组，悬停浮起，一眼定位
- **分类配色**：中央级红色顶边强调，其他区蓝色标题
- 移动端自适应（卡片网格自动收窄）

## 技术

- 纯静态单文件 `index.html`（约 120 KB），无后端、无数据库、无外部 CDN、无统计脚本
- 数据直接硬编码在 HTML 的 `<a class="card">` 标签里
- 样式：纯 CSS，无框架
- 字体：系统字体栈（-apple-system / PingFang SC / Microsoft YaHei）

## 部署

- 仓库：`qinvision/newspaper`
- 发布：GitHub Pages，`main` 分支根目录
- 自定义域名：`newspaper.mydjjm.cn`（见 `CNAME`）
- DNS：阿里云万网 `newspaper` CNAME → `qinvision.github.io`
- HTTPS：Pages 自动签证书，Enforce HTTPS 在证书就绪后于仓库 Settings → Pages 勾选

## 边界

- 本站只是**入口索引**，不存储任何新闻正文、不做镜像
- 链接若失效（报社改域名/改版），直接改 `index.html` 里对应的 URL 推 main 即可
- 数据来源：nez.cn 入口页正文批量抓取，报名已去重并清理末尾数字后缀
