# newspaper · 全国报纸数字版导航

杜绝加密空间旗下子站：**https://newspaper.mydjjm.cn**

## 这是什么

把国内 150 家主流报纸的**官方电子版入口**整理成一张可搜索、按类分组的导航页，点胶囊按钮直接跳到对应报社数字报。

- **150 家**报纸，按性质分 5 类：
  - 中央主要报纸（14）
  - 省级党报（32）
  - 副省级城市党报（15）
  - 省会（首府）城市党报（15）
  - 晚报都市类报纸（74）
- 排名不分先后，链接全部指向报社官方数字报/官网，不转载、不缓存正文

## 功能

- **单行吸顶红条**：标题 + 搜索框 + 实时时钟 + 🎨 主题按钮 + 返回首页，滚动时固定在最上方
- **实时搜索**：在搜索框输入报纸名即时过滤，支持清空，Esc 一键清词
- **8 种主题**：点 🎨 循环切换，选择存在本机 `localStorage`（key: `np-theme`）
  - 经典红 / 深海蓝 / 墨绿 / 紫金 / 暖橙 / 樱花粉 / 青碧 / 暗夜黑
- **分类卡片**：每类一张白卡，右上角显示本类数量，悬停胶囊按钮有浮起动效
- **返回顶部**浮钮（页面下滚 380px 后出现）
- **空态提示**：搜索无结果时给出「未找到相关报纸」提示
- 移动端自适应（≤600px 隐藏标题、紧凑布局）

## 技术

- 纯静态单文件 `index.html`（约 21 KB），无后端、无数据库、无外部 CDN、无统计脚本
- 数据：一个 `categories` JS 数组，每项 `{name, items:[[报纸名, URL], …]}`
- 样式：全部用 CSS 变量驱动，8 套主题只覆盖 `--brand / --accent / --bg / --card / --ink` 等变量
- 字体：系统字体栈（-apple-system / Segoe UI / Microsoft YaHei），无 webfont

## 部署

- 仓库：`qinvision/newspaper`
- 发布：GitHub Pages，`main` 分支根目录
- 自定义域名：`newspaper.mydjjm.cn`（见 `CNAME`）
- DNS：阿里云万网 `newspaper` CNAME → `qinvision.github.io`
- HTTPS：Pages 自动签证书，Enforce HTTPS 在证书就绪后于仓库 Settings → Pages 勾选

## 边界

- 本站只是**入口索引**，不存储任何新闻正文、不做镜像
- 链接若失效（报社改域名/改版），直接改 `index.html` 里对应的 URL 推 main 即可
- 想新增报纸：在 `categories` 对应分类的 `items` 数组里追加一行 `['报纸名','URL']`
